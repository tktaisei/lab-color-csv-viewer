# RGB / Lab Color Visualizer

## 概要
RGB値またはLab値による色の可視化、およびCSVファイルから色データを読み込んで3Dプロット・テーブル表示するWebツールです。

## 主な機能
- RGBまたはLab値を手動入力し、色を3Dプロットで可視化
- CSVファイルから複数色データを読み込み、3Dプロット・テーブル表示
- 色成分セット（R/G/BまたはL/a/b）の複数指定（1~5セット）
- キー列と画像フォルダのマッチングによる画像サムネイル表示
- Plotly.jsによるインタラクティブな3Dグラフ

## 使い方
`index.html` をブラウザで開いてください。

---

### 3Dで色を可視化（単色入力）
上部パネルでRGBまたはLab値を入力し「更新」ボタンで色を表示します。
- 入力した色が3Dプロット（Lab空間）に表示されます。

---

### CSVで色を可視化（複数色・テーブル表示）
下部パネルでCSVファイルを選択し、色データの形式・列を指定して「CSVを表示」ボタンで可視化します。
- CSVの色データがテーブルと色スウォッチで表示されます。
- 必要に応じて色成分セットを追加・削除できます。
- （任意）キー列と画像フォルダを指定すると、テーブル右端に画像サムネイルが表示されます。
## CSVファイル形式
- 1行目がヘッダ（列名）
- R/G/BまたはL/a/bはそれぞれ別の列に格納
- キー列は任意で指定可能

## 依存ライブラリ
- [Plotly.js](https://plotly.com/javascript/)（CDN）
- [PapaParse](https://www.papaparse.com/)（CDN）
